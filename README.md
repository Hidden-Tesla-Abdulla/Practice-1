Приглашение к вводу должно формируется на основе реальных данных ОС, в которой исполняется эмулятор. Пример: username@hostname:~$. 
Реализован парсер, который поддерживает раскрытие переменных окружения реальной ОС (например, $PATH).
Реализованы команды заглушки ls и cd, которые принимают любое количество параметров и выводят свое название и параметры.
Реализована команда exit, которая завершает работу программы.
