Приглашение к вводу должно формируется на основе реальных данных ОС, в которой исполняется эмулятор. Пример: username@hostname:~$. 
Реализован парсер, который поддерживает раскрытие переменных окружения реальной ОС (например, $PATH).
Реализованы команды pwd, history, find, ls и cd:
pwd - показывают путь тек. директрории
history - выводить историю команд
find - поиск по критериям(type или name)
ls - команда для просмотра файлов;
cd - для перехода в директорию;
Реализована команда exit, которая завершает работу программы.
Реализована поддержка двух аргументов: для VFS и стартового скрипта
Реализована возможность подключить VFS. VFS подключается через CVS файл.
